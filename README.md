# Saudi E-Commerce Store Insights

Power BI | Python | DAX | Power Query | Excel

> An interactive data analytics project analyzing **5,401 Saudi e-commerce stores** to understand store activity, categories, customer ratings, and digital presence.

---

# 📊 Project Snapshot

| Metric | Result |
|---|---:|
| 🏪 Total Stores | **5,401** |
| 🟢 Active Stores | **4,892** |
| 📈 Active Rate | **90.59%** |
| ⭐ Average Rating | **8.60 / 10** |
| 🏷️ Categories | **15** |

---

# 🎯 What I Analyzed

- Store Activity & Status
- Business Category Distribution
- Customer Ratings
- Number of Ratings
- Website & Social Media Presence
- Relationship between Digital Presence, Activity & Ratings

---

# 🔍 Key Insights

🟢 **90.59%** of stores were classified as Active.

⭐ The overall average store rating was **8.60 / 10**.

🏷️ The dataset contains **15 business categories**.

🌐 Stores with broader digital presence showed higher average ratings and activity levels in this dataset.

**Average Rating:**

`Website Only → 8.15`

`Website + Instagram → 9.59`

`Website + Twitter → 9.23`

`Website + Instagram + Twitter → 9.71`

> These results represent observed associations within the dataset and do not establish causation.
